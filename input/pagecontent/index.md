_Computable Name_: NLCoordinationClinicalWorkflows

This implementation guide defines a minimal Task-based clinical workflow for Dutch care coordination. It is intentionally limited to the two Task profiles described in the TA Workflow document: `NLCoordinationTask` and `NLCancellationRequestTask`.
