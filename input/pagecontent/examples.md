# Examples

This guide includes a small set of examples to illustrate how the profiles are used.

## Included examples

- `Example-NLCoordinationTask` — a coordination task for specialist review and discharge planning
- `Example-NLCancellationRequestTask` — a cancellation request task that targets an active coordination task
- `Example-NLCoordinationServiceRequest` — the request referenced by the coordination task
- `Example-NLCoordinationPatient` — the patient context for the request and task

## Purpose

These examples are illustrative and are intended to show the relationship between the workflow Task and the underlying request.
