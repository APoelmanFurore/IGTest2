# Conformance

This guide includes a small set of conformance artifacts in addition to the Task profiles.

## SearchParameter definitions

The guide defines SearchParameter resources for locating coordination tasks by:

- focus
- owner
- status

These definitions make the package more explicit and support interoperable task retrieval.

## CapabilityStatement

The guide defines a CapabilityStatement that describes the expected Task support for a system that implements this workflow. It documents:

- support for the two Task profiles
- read, update, search, and create interactions on Task
- support for the defined search parameters

## Scope

These conformance artifacts are limited to what is needed to publish a coherent FHIR package around the workflow described in the guide.
